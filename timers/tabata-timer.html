Common questions

Why 20 seconds work and 10 seconds rest?

That's Dr. Izumi Tabata's original protocol from a 1996 study on high-intensity interval training — short enough to sustain near-maximal effort, with just enough rest to repeat it eight times.

Can I change the work/rest lengths or round count?

Yes — all three (work seconds, rest seconds, rounds) are editable before you start. It stops being strictly "Tabata" once you change the classic 20/10 ratio, but the same shared-link mechanic works for any interval ratio.

Does everyone see the same round at the same time?

Yes — like every timer here, the cycle's start instant is encoded in the link itself, so every device computes the current round and phase independently from the same starting point, with no server keeping them in sync.
