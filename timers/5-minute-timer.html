Common questions

How accurate is a 5 minute shared timer?

Accurate to about a second. Each device counts down independently against the same shared deadline using its own clock, so there's no server lag to introduce drift between screens.

Can more than one person use the link at once?

Yes — any number of people can open the same link at the same time. There's no viewer limit, because nothing is streamed to them; each device just does its own math against the timestamp in the URL.

Does it still work if I close the tab and reopen it?

Yes. Reopening the link re-reads the same deadline from the URL and picks up exactly where the countdown should be — nothing resets.
