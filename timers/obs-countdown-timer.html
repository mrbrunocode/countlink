Add it to OBS in 3 steps

  1. In OBS, go to Sources → + → Browser.
  2. Paste the overlay link below (not the regular sync link) and set the size — 400×160 is a good starting point.
  3. Check "Shutdown source when not visible" to save CPU between uses.

Common questions

Will the background really be transparent in OBS?

Yes — the overlay link removes the page background entirely (not just visually dark, genuinely transparent), so only the countdown digits appear on your scene, with no chroma key or green screen needed.

Does the countdown keep running if I switch OBS scenes?

Yes, as long as the Browser Source stays loaded — if you enable "Shutdown source when not visible," OBS will reload it when the scene becomes active again and it will recalculate against the same shared deadline correctly.

Can I resize the overlay without it looking blurry?

Yes — the digits are rendered as live text (not an image), so resizing the Browser Source in OBS stays sharp at any size.
