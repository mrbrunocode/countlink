Common questions

Do all the timers share one countdown, or run independently?

Independently — each timer you add has its own name and its own end time. Adding, removing, or finishing one has no effect on the others.

How is the set of timers kept in sync across devices?

The same mechanic as every other page here: each timer's end instant is encoded in the page's link. Copy the link after adding your timers, and anyone who opens it sees the identical set, each counting down from wherever it currently is.

Is there a limit to how many timers I can add?

No hard limit, but a screen full of dozens of cards gets hard to scan — for most uses (cooking a multi-dish meal, running parallel breakout timers) a handful at once is the practical ceiling.

Can I remove just one timer without resetting the others?

Yes — each card has its own remove button; removing one leaves the rest of the set (and the shareable link) intact.
