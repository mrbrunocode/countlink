Common questions

Is this a real Pomodoro timer with work/break cycles?

It's a single 25-minute countdown, not an automated cycling timer — start it again for your next Pomodoro, or use the count-up/stopwatch mode if you'd rather track elapsed focus time instead.

Can my whole study group use the same 25-minute block?

Yes — share the link once and everyone's focus block, and everyone's break, starts and ends at the exact same moment, since it's all counting down to one shared timestamp.

Does the timer make a sound at the end?

Yes, a short chime plays when it hits zero (toggle it off with the Sound button if you'd rather work in silence).
