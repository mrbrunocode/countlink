Standard text field for forms: timer names, join codes, email capture.

```jsx
<Input label="Timer name" placeholder="Launch countdown" helperText="Visible to everyone with the link" />
```

Set `error` + `helperText` together to show a validation message in danger color. `prefix`/`suffix` accept icons or short labels (e.g. a "countlink.app/" prefix on a share-code field).
